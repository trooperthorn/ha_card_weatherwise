# Documentation index

- `design.md`: what the card is for, how it is structured, why the forecast
  is fetched in the browser, how interval selection and staleness work, and
  the WMO condition mapping.

  verified on which date, and what remains unverified.
- `operations.md`: every configuration option and its consequences, the two
  kiosk views, and how to read the stale, expired, and unavailable states.
- `decisions.md`: dated decisions with the alternative rejected and why.
- `backlog.md`: open items, dated.
